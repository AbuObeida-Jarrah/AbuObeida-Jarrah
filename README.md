## 🧠 About

I'm **Obeida** ([@AbuObeida-Jarrah](https://github.com/AbuObeida-Jarrah)) — a programmer in progress who likes to understand how things work all the way down. I practice C through the 1337 / 42 exercise track, build modern web interfaces with Astro, and explore Python tooling on the side.

أنا **أوبيـدا**، أتعلّم البرمجة عبر تمارين 1337 / 42 في لغة C، وأبني واجهات ويب بـ Astro، وأجرّب أدوات Python. أؤمن أن أفضل طريقة للتعلّم هي أن تنشر ما كتبته، لذلك هذا الحساب هو سجلّ تقدّم مفتوح للجميع.

- 🔭 **Currently learning:** C — pointers, memory management, recursion, and clean coding habits.
- 🛠️ **Building:** modern websites (Astro 5 + Tailwind 4) and terminal tools in Python.
- 🎯 **Goal:** turn daily exercises into strong engineering fundamentals.
- 🎲 **Fun fact:** my first archived solution was `ft_putchar`. 101 exercises later, I'm still writing C by hand.
