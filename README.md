## 🧠 About / نبذة

I'm **Obeida** ([@AbuObeida-Jarrah](https://github.com/AbuObeida-Jarrah)) — a student and curious programmer who loves understanding how things work from the inside out. My focus is **cybersecurity through low-level programming**: C first, Python alongside it. I practice through the 1337 / 42 exercise track, and I keep everything I learn in public as a record of progress.

أنا **أوبيـدا**، طالب ومحبّ للبرمجة، أهتم بالأمن السيبراني من زاوية البرمجة منخفضة المستوى: C كلغة أساسية، وPython أتعلمها إلى جانبها. أتدرّب عبر تمارين 1337 / 42، وأفضّل أن يكون تعلّمي أمام الجميع ليكون سجلاً حقيقياً لتقدّمي.

- 🔐 **Direction / الاتجاه:** cybersecurity, systems, and understanding software at the lowest level.
- 💻 **Favorite language / لغتي المفضّلة:** **C** — simple, powerful, and close to the machine.
- 🐍 **Also learning / أتعلم أيضاً:** Python — step by step, for scripting and tooling.
- 📐 **Still studying / ما زلت أدرس:** mathematics, physics, and science in general.
- 🌱 **Mindset / الفكرة:** I love learning anything new, especially anything I can use in my real life.
- 🎲 **Fun fact:** my first archived solution was `ft_putchar`. 101 exercises later, I'm still writing C by hand.
